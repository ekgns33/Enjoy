# LeetCode Mock Interview - 2

* 이번 online 평가에서는 두문제가 출제되었다.&#x20;

1시간동안 두 문제를 풀어내야했기에 시간을 최대한 적게 사용하면서 정확하게 풀어내는게 중요했다.



1. 학생 출석 레코드 필터링

첫번째 문제는 그냥 string 로그를 읽고 학생의 지각횟수, 결석 횟수를 세는 문제로 쉽게 풀었다.



2. 네트워크 지연시간&#x20;

요 문제는 조금 재미있었는데, 각 노드에서 다른 노드에 edge들이 있을때 edge의 weight가 바로 네트워크 전송에 걸리는 시간이었다. 주어진 노드들은 그래프를 형성하고, 모두 이어져있는 문제였다.&#x20;

* 풀어야 할 것 : 한 노드에서 전체 노드까지 링크(연결)하는데 걸리는 최소 시간.

링크라는 단어가 조금 어색하지만 탐색 시간으로 이해하면 dfs 유형의 문제라는 것을 알 수 있다. 위 문제를 그냥 그래프 유형의 문제로 치환하면 다음과 같다.

* **한 노드에서 다른 노드까지 걸리는 최소시간들 중 최대시간. == 다익스트라 활용**

모든 링크에 전달해야하기때문에 어쩔 수 없이 방문해야하지만 갈 수 있는 방법은 여러가지일 수 있다. 그중 우리는 전체에 도달하는 최소시간을 원하기 때문에, 한노드에서 다른 노드까지의 걸리는 최단거리들 중 최대 시간을 구하면 된다.
