* 문제를 해석하고 솔루션을 찾아가는 과정이 재미있다. 알고리즘의 늪..



앞으로 mock-interview를 할때마다 글을 적어보려한다.



### 오랜만에 보는 모의코테 후기



3문제가 나왔다.&#x20;

* 첫번째는 일반적인 dfs문제 (섬의 둘레구하기)
* 두번째는 Single Linked List에서 교차 순서로 배치하기
* 세번째는 dfs + grapsh 문제로 그래프 deep-copy하기

Phone Interview 항목을 골라서 그런지 난이도가 그리 어렵지는 않았다. << 제한시간안에 풀었다는 의미.

음... 점수가 높지 않다. 이유는 알고있다.



1. 첫번째 문제는 15분안으로 풀이 했다. 나쁘지않은 속도
2. 두번째에서 조금 고민을 했다. 풀이법이 두가지로 나뉜다.
   1. 자료구조에 저장하고 합치기
   2. reverse를 구해서 머지하기

문제의 의도는 리스트의 가운데 중앙값 노드를 구하고 뒤집어서 머지하는 것이다. 방향은 잘 잡았는데 **reverse해서 저장해야겠다라는 이상한 생각에 빠져서 space를 O(n)을 썼다**. 고민하는데에도 시간이 꽤 들었다.

3. 이 문제가 골때린다. 문제는 바로 이해해서 dfs로 풀었는데 오버플로우가 나서 시간을 20분은 쓴 것 같다. 어이 없게도 **dfs함수가 아니라 clonedGraph라는 함수를 호출**해서 생긴 오버플로우였다. 항상 뭐가 안될때는 코드를 다시 읽어보자.

***

**자가 피드백**

1. 코드를 작성할때 조금 천천히 작성하자. 코드 잘못쳤다가 고치느라 드는 시간 + Run횟수가 많이 든다.
2. 자료구조에 꼭 저장할 필요가 있는지 생각해보자. in-place로 가능하면 그게 좋으니까.
3. example input을 내 코드에 넣고 빠르게 머리나 적으면서 돌려보는 것을 습관화하자. 오랜만에 하니 다 까먹었다.
